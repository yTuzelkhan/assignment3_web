## Part 3. Combined Project

### Task 4. Responsive Portfolio Page
The final part combines both approaches to create a personal portfolio. It uses Bootstrap for the main structural layout (Navbar, Grid system for the main content and sidebar, Cards for projects) and custom CSS media queries to adjust typography and spacing for different screen sizes. Real project links (YOLOv8 and Telegram Bot) are integrated into the cards.

## Summary of Work Process
During this assignment, I learned how to build fluid and responsive layouts. Initially, I practiced using raw CSS with Flexbox and `@media` queries to understand how breakpoints work and how to calculate element widths dynamically (using `flex-basis`). Then, I transitioned to Bootstrap 5, which significantly sped up the development process by providing pre-built responsive grid classes and UI components like the collapsible Navbar. Finally, I combined both techniques to build a practical portfolio page, ensuring it is visually appealing and functional across all device sizes. The project was successfully linked together and deployed via GitHub.
